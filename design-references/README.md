# Stitch UI Reference

This directory contains the original Coldingrod Stitch exports supplied for implementation reference.

- Treat `DESIGN (1).md` and `coldingrod/DESIGN.md` as the primary Coldingrod visual direction.
- Treat `executive_precision/DESIGN.md` as an optional variant until explicitly selected.
- Use screenshots and HTML exports as visual/interaction references.
- Do not paste the standalone HTML over the Next.js application.
- Implement approved screens through the existing React, Tailwind CSS, and Base UI component system.

The reference package currently covers the app shell, dashboard, clients, leads, meetings, AI, settings, onboarding, notifications, proposals, and analytics.
